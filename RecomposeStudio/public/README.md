# Static assets, served at the site root

`recompose-logo.png` is the **source lockup** as delivered — the R mark, the
`Recompose` wordmark, and the `AI DESIGN COMPANY` line. Everything else here is
derived from it, so re-deriving is possible if it is ever redrawn:

- `recompose-mark.png` — the R alone, cropped to its alpha bounding box.
- `favicon-32.png`, `favicon-180.png` — that mark centred on a square canvas.

**The mark is used, not the lockup, and both reasons matter.** The wordmark is
white with a light outline, so it is invisible on this app's daylit chrome; and
at 16px a wordmark is a smudge while an R still reads. The header therefore
pairs the mark with the name set in the shell's own type, which is also the
honest thing for a tool — the studio is not a marketing surface.
